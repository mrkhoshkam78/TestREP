# Pixelverse — Gaming Discovery Website

A Persian, right-to-left, responsive gaming discovery website with a 3D-inspired interface.

## Run

No installation, build step, server, API key, or internet connection is required.

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

## Features

- Responsive Persian RTL layout.
- 3D hero scene, floating UI elements, and pointer-based depth/tilt effects.
- Twelve curated PC game profiles with original vector poster artwork.
- Instant search, genre filters, and sorting.
- Favorites saved locally in the browser (`localStorage`).
- Game detail modal and random-game picker.
- Mobile navigation and reduced-motion support.
- All artwork and application code are included locally; no external API or remote assets are required.

## Project structure

- `index.html` — page structure and content
- `styles.css` — visual design, responsive layout, and 3D effects
- `app.js` — game catalog and interactions
- `assets/` — original SVG poster illustrations

On Windows, you can also double-click `open_pixelverse.bat` to open the homepage in your default browser.

The poster images are original decorative vector illustrations made for this interface; they are not official game cover art.
